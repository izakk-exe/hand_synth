## Nouveautés v1.0.3

### Nouveau : version web mobile et tablette
Une version 100 % navigateur est maintenant hébergée à
**https://izakk-exe.github.io/hand_synth/app/** — fonctionne sur
iPhone, iPad, Android, et toute tablette avec caméra. Interface
tactile remaniée, boutons plus gros, menu scrollable, caméra frontale
par défaut, démarrage en un tap pour satisfaire les contraintes iOS.
Installable comme application via "Ajouter à l'écran d'accueil".

### Nouveau : 14 instruments
Au lieu des 5 précédents (piano, pad, pluck, orgue, flûte), la liste
passe à 14 : + **xylophone, marimba, cloches, harpe, cordes, basse,
synthé lead, voix, guitare**. Disponibles dans les réglages, dans le
mode Créer, et en gros boutons tactiles sur la version mobile.

### Retiré : onglet Chansons
Le mode Chansons est retiré de cette version. L'accent est mis sur
les deux usages principaux — musique libre et manipulation sensorielle
— et sur le mode Créer simplifié introduit en 1.0.2.

### Premier lancement
Windows affichera "éditeur inconnu" (logiciel non signé). Cliquer sur
**Infos complémentaires → Exécuter quand même**. Palma est MIT, 100 %
hors-ligne après téléchargement.

### Configuration requise
Windows 10/11 · 64 bits · webcam · 4 Go RAM · GPU WebGL.
Pour la version mobile : navigateur récent, caméra, iOS 14+/Android 10+.
